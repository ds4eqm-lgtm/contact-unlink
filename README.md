# 묶인 연락처 풀기

안드로이드(삼성 갤럭시 포함) 전화번호부에서 저절로 묶인(연결된) 연락처를 찾아 원인을 보여 주고 풀어 주는 앱입니다.
연락처 내용은 바꾸지 않고, 묶음만 나눕니다.

- 앱 받기: [download/contact-unlink.apk](download/contact-unlink.apk)
- 사용설명서: [download/사용설명서_0.2.txt](download/사용설명서_0.2.txt)
- 같은 사람 기준: 이름이 글자 하나까지 완전히 같을 때만 같은 사람 후보로 봅니다.

앱은 켤 때 app/version.json을 보고 새 판이 있으면 스스로 받아 설치 화면을 엽니다.
