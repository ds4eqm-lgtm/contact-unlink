# 묶인 연락처 풀기

안드로이드(삼성 갤럭시 포함) 전화번호부에서 저절로 묶인(연결된) 연락처를 찾아 원인을 보여 주고 풀어 주는 앱입니다.
연락처 내용은 바꾸지 않고, 묶음만 나눕니다.

- 앱 받기: [download/contact-unlink.apk](download/contact-unlink.apk)
- 사용설명서: [download/사용설명서_0.14.txt](download/사용설명서_0.14.txt)
- 같은 사람 기준: 이름·번호·이메일·홈페이지·메모·프로필 사진(원본 바이트까지) 등 모든 칸이 100% 같을 때만 같은 사람으로 봅니다.
- 백업: 모든 칸과 원본 사진을 손실 없이 휴대폰 다운로드 폴더에 저장하고 원본과 비교합니다. 백업은 GitHub에 올라가지 않습니다.

앱은 켤 때 app/version.json을 보고 새 판이 있으면 묻지 않고 스스로 받아 설치합니다(안드로이드 12 이상, 처음 한두 번만 확인).
