묶인 연락처 풀기 PC판

1. PC 보관 폴더
모바일 폰 백업을 보관할 PC 폴더를 한 번 골라 주세요(예: 문서 안에 "연락처보관" 폴더를 새로 만들어 고르기). 그 안에 모바일 폰과 똑같이 "묶인연락처풀기" 폴더가 생깁니다.

2. 모바일 폰 → PC (와이파이)
누르실 것 없습니다. 이 PC판을 켜 두고 모바일 폰 앱을 켜면, PC가 같은 와이파이에서 모바일 폰을 저절로 찾아 아래 불이 차례로 켜지고, 지난번 보관 폴더에 그대로 백업합니다(새로 생기거나 바뀐 것만. 이름·전화번호·메일·홈페이지·메모·사진 중 글자·마침표·띄어쓰기 하나, 사진 한 바이트만 달라도 바뀐 것으로 보고 다시 받습니다. 파일마다 SHA-256 지문값으로 엄격하게 비교). 처음 보는 모바일 폰이면 "백업할까요?"를 한 번 묻고, 번호 6자리를 한 번만 넣으면 다음부터는 묻지 않습니다.
못 찾을 때: 주소 직접 넣기주소 번호
📵 백업·보내기 중에는 모바일 폰 화면은 꺼도 됩니다. 모바일 폰 최근 앱 화면의 [모두 닫기]는 누르지 마세요. 모바일 폰 앱이 꺼져 멈춥니다.
3. 모바일 폰 → PC (USB 선) 저절로 백업
USB 선만 꽂으면 됩니다. 불이 위에서부터 차례로 초록으로 켜지고, 확인할 곳마다 5, 4, 3, 2, 1 뒤에 저절로 넘어갑니다. 바꾸고 싶으면 그 줄의 [바꾸기]나 [■ 자동 멈춤]을 누르세요.
📵 백업·보내기 중에는 모바일 폰 화면은 꺼도 됩니다. 모바일 폰 최근 앱 화면의 [모두 닫기]는 누르지 마세요. 모바일 폰 앱이 꺼져 멈춥니다.
PC 도우미 없이 손으로 하기(예전 방식)
  1. 모바일 폰을 USB 선으로 PC에 꽂고, 모바일 폰 화면 위 알림에서 [USB 사용 목적] → [파일 전송]을 고릅니다.
  2. PC의 파일 탐색기 → 내 PC → (모바일 폰 이름) → 내장 메모리 → Download 로 들어갑니다.
  3. "묶인연락처풀기" 폴더를 위 1번에서 고른 PC 보관 폴더 안으로 끌어다 놓아 복사합니다(사진이 많으면 시간이 걸립니다).
  4. 다 복사되면 아래 단추를 누릅니다. 사진 하나하나를 지문값(SHA-256)으로 확인해, 한 바이트라도 다르거나 빠진 것을 알려 줍니다.
4. 새 모바일 폰으로 옮기기 (백업을 보내고 바로 연락처에 넣기) 자동 없음: 3단계 확인을 모두 거쳐야 넣습니다
새 모바일 폰을 같은 와이파이에 연결하고 아래 차례대로 하면, 단추 하나로 보내기부터 연락처에 넣기까지 끝납니다. 끝나면 새 모바일 폰의 연락처 앱에서 바로 쓰시면 됩니다. 넣기 전에 ① 연결된 모바일 폰이 맞는지(기기 번호로 지금 쓰는 대표님 모바일 폰인지 알아봄) ② 덮어쓰기 / 지우고 덮어쓰기 중 무엇으로 할지 ③ 확인 숫자 4자리, 이렇게 3단계를 확인합니다. 지금 쓰는 모바일 폰이면 지우는 쪽은 고를 수 없습니다.

와이파이가 없을 때: USB 선으로 보관 폴더 안의 "묶인연락처풀기" 폴더를 모바일 폰 내장 메모리 → Download 안에 다른 이름(예: "PC에서")으로 복사하고, 모바일 폰 앱 [백업·되살리기]의 [📁 PC에서 모바일 폰에 복사해 둔 백업 폴더 불러오기]로 그 폴더를 고릅니다. 불러오기가 끝나면 묻지 않고 바로 연락처에 넣습니다.
5. PC → 모바일 폰 되살리기 (USB 선, 스마트 스위치처럼)
USB 선을 꽂으면 PC 백업을 모바일 폰으로 보내고, 모바일 폰 앱이 바로 연락처에 넣습니다. 자동으로 시작하지 않습니다. [PC 백업을 이 모바일 폰에 넣기]를 누르면 4번과 똑같이 ① 연결된 모바일 폰이 맞는지(기기 번호로 지금 쓰는 대표님 모바일 폰인지 알아봄) ② 덮어쓰기 / 지우고 덮어쓰기 ③ 확인 숫자 4자리, 3단계를 확인한 뒤 넣습니다. 지우고 덮어쓰기는 그 모바일 폰에 원래 있던 옛 연락처(모바일 폰·SIM)를 먼저 원본 그대로 백업해 두고 지웁니다 (구글 계정 연락처는 건드리지 않음, 같은 기계면 모바일 폰 앱이 스스로 지우지 않음).
